## Confirmed fixes

- Mail action enhancements accumulated on retained tables across refreshes. Replaced the previous enhancements before rendering the current actions. Verified one DNS action per domain and one login/configuration pair per mailbox after deployment.
- Text action buttons inherited icon-only widths, clipping their labels. Gave text actions intrinsic width and allowed mail action rows to wrap.
- Generic secondary-button styling overrode close-button backgrounds. Excluded close controls; verified the Create database dialog's rounded red close button live.
- Vertically centered dropdown arrows for compact inputs.
- Corrected file-picker vertical spacing, including migration forms.
- Added gaps between adjacent update/migration buttons.
- Prevented hostname settings cards from stretching to the height of their neighbour; improved environment-detail readability.
- Put extension search, version and state filters on one row on wide screens, with a single-column fallback.
- Constrained opened website-tool forms and FTP inputs to readable widths.
- Shortened extension and website-backup help; removed repeated settings page descriptions; made shared help text readable.
- Corrected the Recent Activities tooltip copied from Settings.
- Reduced empty-state padding and made service/empty-state headings consistent.

Website action images initially appeared absent during loading, but displayed correctly in the settled page. They were retained.
